# 画图：先选出视觉语言

用户要画图。先 Read `~/.cursor/skills/diagram-style-catalog/SKILL.md`。

## 必须先出菜单（未点名时）

用户**没有**写出 Skill 名、也**没有**贴对照截图/明确图种时：

1. 用 AskQuestion 列出目录 §1 的视觉语言，选项用中文名，括号里写 skill 名。
2. 等用户选完，再 Read 对应 Skill，然后才开始画。
3. 未选定前禁止画 Mermaid、禁止直接上画板。

用户已经点名（如「分层行动胶囊图」「走 `layer-action-capsule-diagram`」）或贴了对照图：跳过选择题，直接走对应 Skill。

交卷地点（飞书画板 / HTML / draw.io）未说清时，再问一句媒介，选项见目录 §2。
