# 深色分层彩色卡片墙（内联 SVG）

深色整图底 + 每层描边色框 + 层内深彩色卡片。上→下是归属（应用在上、硬件/PDO 在下），不是时序。层间只用一行 `↓ 说明 ↓`，不用箭头连线。

不确定图种 → `diagram-style-catalog`。
交卷：目标 `.md` **内联 SVG**（开标签同一行、内部无空行）。禁止 Mermaid `flowchart` 硬凑。禁止改 PNG / `![](图)`。禁止写成 `.figures/` sidecar HTML。

对照实现：`wdf-overview.md` 第 1 节。色板与 `markdown-to-html` §3 同一套，只换媒介。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 按层堆叠的模块/栈/能力清单，要嵌进 `.md` | 浅底白分组彩卡片、飞书画板 → `fig-tinted-layer-cards` |
| 层内 2～4 张条目卡，或一层再分 2 个分组 | HTML 页 / sidecar `.layer` → `markdown-to-html` §3 |
| 层间一句↓，底栏色块图例 | 关/改/加/留胶囊 → `layer-action-capsule-diagram`；左栏常驻+顶栏胶囊 → `fig-dark-platform-stack`；左栏层名+色带+右侧竖条 → `fig-dark-layer-bands` |
| 读者要看见「谁在哪一层」，不要跨层折线 | 关系/流向 SVG → `fig-dark-layer-relations`；仍要 Mermaid 围栏 → `mermaid-flowchart-layout`；谁的道+时间 → 泳道；中心+卫星功能清单 → `fig-hub-function-map` |

用户只说「深色分层卡片」没点名媒介：默认仍走 HTML sidecar。**点名 SVG / 落本地 md** 才用本 skill。

## 结构（上→下）

1. **标题** 20 bold `#F0F6FC` 居中（最近小节 + 图意，无句号；禁止「示意图」「架构图」）
2. **副标题** 13 `#8B949E` 居中（可省略）
3. **层**（可重复，建议 4～6 层）
4. **层间** `↓ 一句话 ↓` 12 `#8B949E` 居中
5. **底栏图例**：14×14 色块（填=内卡片色，描边=层 `border`）+ 层名

层内部：

```
╔ #0D1117 层底 + 彩色描边 ══════════════════════╗
║ 层名（左，15 bold）          副标题（右，12） ║
║ [深色卡] [深色卡] [深色卡]                     ║
╚══════════════════════════════════════════════╝
```

- 同层默认 3 列卡片；4 个条目用 4 列；条目少可 2 列。
- 一层要对照两组（会碰到 / 不会做）时，用两个分组框，框内再放卡片。
- 卡片文案：**标题一行 + 说明一行**，不写长段。

## 色板（硬规则）

上→下默认 **灰 / 蓝 / 橙 / 紫 / 绿**；管理面才用红。层不够就截取，不要发明第六语义色。相邻层必须换色。同层描边、内卡片、标题色一致。

| 槽 | 语义 | 描边 `border` | 内卡片 `fill` | 字 `text` |
|----|------|---------------|---------------|-----------|
| 灰 | 应用 / 软件 PDO / 硬件清单 | `#484F58` | `#21262D`（应用）`#161B22`（PDO） | `#C9D1D9` / `#8B949E` |
| 蓝 | 用户态库 Win32 / ntdll | `#58A6FF` | `#0D2137` | `#79C0FF` |
| 橙 | I/O 管理器 / 服务 | `#F0883E` | `#1A150D` | `#FFCC80` |
| 紫 | 框架（KMDF / 运行时） | `#A371F7` | `#1A1428` | `#D2A8FF` |
| 绿 | 本仓库模块 / `.sys` | `#3FB950` | `#122117` | `#7EE787` |
| 红 | 管理面（少用） | `#F85149` | `#2D1215` | `#FFA198` |

固定件：

| 件 | 值 |
|----|-----|
| 画布 | `#0D1117`，圆角 12，开标签 `style` 写 `background:#0D1117` |
| 层底 | `#0D1117`（不要和内卡片同色） |
| 层/分组描边 | 该层 `border`，宽 2，`rx="8"` |
| 内卡片 | `rx="6"`，描边宽 2 |
| 字体 | `sans-serif`（与仓库泳道一致） |

图下用「灰 / 蓝 / 橙 / 紫 / 绿」指**描边色**时，`<span>` 字色等于该层 `border`（灰用 `#8B949E`，否则 `#484F58` 在深底上看不见）。

## 几何

根：宽 **1100**。内容 x=28、宽 1044。标题区高约 72。

| 元件 | 建议 |
|------|------|
| 层框 | 高 = 页眉 38 + 卡片行；padding 左右 14 |
| 3 列卡 | x=`42 / 383 / 724`，宽 333，高 60～70，列隙 8 |
| 4 列卡 | x=`42 / 298 / 554 / 810`，宽 248（末列 246），高 70 |
| 2 分组 | x=`42 / 558`，宽 `500 / 498`，框内再 2 卡 |
| 层间↓ | 单独约 20px 行，不要画 `path` / `marker` |
| 图例 | 底栏 y 距末层 12，色块 14×14 |

卡片增减就重算层高和 `viewBox` 高度，不要压缩字号去塞旧框。中文一行约 14 字；超了换行或减字，禁止 `<foreignObject>`。

## SVG 交卷（硬规则）

1. `<svg xmlns … viewBox="0 0 1100 H" … style="…background:#0D1117…">` **同一行写完**。
2. SVG **内部禁止空行**；分组用 `<!-- app -->`。`</svg>` 后可以空行。
3. 可见标题用 `<text>`，与 `<title>` 同文。
4. 层间关系只写 `↓ … ↓` 文本。禁止 `edge`、禁止跨层折线。
5. 写完跑 `audit_mermaid.py`（收 `svg-blank` / `svg-open-split`）。

## 禁止项

- 浅色整图底、白分组框、饱和色实心卡当浅色墙
- 飞书画板「导出 SVG」（常是一张 `<image>`，不是矢量真源）
- `foreignObject`、PNG、sidecar `.layer`
- Mermaid `flowchart` / `subgraph` 冒充层框
- 关/改/加/留胶囊、左栏 L0–L7 色带
- 层底和内卡片同填色糊成一块
- 相邻层同色
- 为预览空白改 `![](….png)`
