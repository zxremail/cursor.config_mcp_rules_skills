# 深彩色上下交错时间线

一条水平中轴，节点等距（或另附真实比例条），卡片在轴的**上 / 下交错**。
每张卡片：顶栏写墙钟区间，正文写阶段名、时长、屏幕上或事件上看到的内容。
默认**深底 + 深彩色整卡 + 白字**，适合暗色预览。

不确定图种 → `diagram-style-catalog`。
交卷：目标 `.md` **内联 SVG**。禁止 Mermaid `timeline` / `gantt` / `flowchart` 硬凑。
禁止改 PNG / `![](….png)` / `![](….svg)` 迁就预览。

对照实现：`boot-animation-timeline.md` 的「暗色主题交错时间线」与「暗色主题阶段条带」。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 一条墙上的先后阶段 / 里程碑，读者要同时看见时刻和短说明 | 阶段 × 季度排期、菱形里程碑泳道 → `task-roadmap-timeline` |
| 卡片上下交错、中轴圆点，像产品史 / 开机画面交接 | 谁在哪周做哪块 → `task-assignment-timeline` |
| 时长差一个数量级（0.4 s 对 7.2 s），等距卡片 + 比例条 | 模块作业交接、谁的道 → 水平/垂直泳道 |
| 用户说「时间线」且对照上下卡片截图 | 消息往返 → `sequenceDiagram` / `html-sequence-swimlane` |

## 默认：深彩色（暗色主题）

使用深彩色配色方案，以便适合在暗色主题环境中查看，同时保持良好的对比度和可读性。

| 元素 | 值 |
|------|-----|
| 画布 | `#0D1117`，圆角 8，开标签 `style` 写 `background:#0D1117` |
| 轴线 / 茎 | `#555577`，虚线 `6 6` |
| 轴旁字 | `#C9D1D9` |
| 卡片字 | 标题 `#FFFFFF`，说明 `#E8EAED` |
| 字体 | `'Noto Sans CJK SC','Noto Sans CJK TC',sans-serif`（CSS 里多词家族必须加引号） |

阶段色循环（`fill` / `stroke`，字一律白）：

| 序 | fill | stroke |
|----|------|--------|
| 1 | `#6A4C93` | `#4A3566` |
| 2 | `#2E86AB` | `#1B4965` |
| 3 | `#2D936C` | `#1E6B4E` |
| 4 | `#F18F01` | `#C67500` |
| 5 | `#3D5A80` | `#2B3F5C` |
| 6 | `#A23B72` | `#6E284E` |
| 7 | `#C67500` | `#8A5100` |
| 8 | `#3370FF` | `#1B4965` |

超过 8 个从第 1 色再转。顶栏用 **stroke 色**，卡身用 **fill**。圆点：外圈 fill、内心 fill、环底画布色。

**浅色版**（白卡 + 浅顶栏 + 深字）只在用户明确说「对照浅色截图 / 浅色卡片墙 / 不要深底」时另画。默认只交深彩色。两版并存时浅色保留、深色另起一节，不要覆盖浅色。

图下若用「紫 / 蓝 / 绿 / 橙」指卡色，色名字色必须等于该图 `fill`（`markdown-export` §10）。小图不写独立图例。

## 几何

```
[卡1 上]     [卡3 上]     [卡5 上]     [卡7 上]
    ●-----------●-----------●-----------●------  中轴
        [卡2 下]     [卡4 下]     [卡6 下]     [卡8 下]
```

- 奇数节点在**上**，偶数在**下**（从 1 起）。
- 主图节点**等距**，保证短阶段卡片仍能读。
- 卡片建议 `200×148`，顶栏 28px。标题拆两行：「第 N 阶段」+ 短名。说明最多两行，一行约 14 个汉字。
- 卡片中心对齐圆点；竖茎从卡边接到轴，不要穿过卡。
- 文字必须完整露出：加宽卡或拆行，禁止把字号缩到看不清。
- 轴左短注平台/读法，轴右短注终点时刻。

**比例条（时长不均时必加第二张）：**

- 同一套阶段色，按真实墙钟宽度堆叠。
- 画布同样深底白字。
- 窄到写不下标签的段：序号写在条**上方**。
- 没有持续时间、只有「进入某状态」的终点：竖线 + 圆点，不要画成一段色带。

## SVG 硬规则

与 `markdown-export` 内联 SVG 同一套：

- `<svg>` 开标签**同一行**写完（`xmlns` / `viewBox` / `width` / `style`）。
- `<svg>…</svg>` **内部禁止空行**；分组用注释。`</svg>` 之后可以空行。
- 先铺满画布的深底 `<rect>`，再画轴和卡。
- 落盘后跑 `python3 ~/.cursor/skills/markdown-export/scripts/audit_mermaid.py <md>`。

## 禁止

- 用 Mermaid `timeline` / `gantt` / `flowchart` 冒充交错卡片。
- 只画等距点、把 0.4 秒和 7 秒画成一样宽，又不给比例条（时长差大时）。
- 默认交浅底白卡（除非用户点名浅色）。
- 深底上用 `#1F2329` / `#333` 字。
- 无引号的 `font-family:Noto Sans CJK SC`（会被拆成多个家族，中文落空）。
- 业务专名写进 Skill；阶段文案留在文档。
