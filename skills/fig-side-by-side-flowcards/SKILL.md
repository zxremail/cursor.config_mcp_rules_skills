# 并排竖卡流程图

一条因果链拆成 **左、右两张等高竖卡**。卡内从上到下。跨卡用 **直角折线**：从左卡最后一框的右边出去，竖着上去，再进右卡第一框的左边。
交卷：目标 `.md` **一张内联 SVG**（同一坐标系）。色板、SVG 空行/开标签、PNG 禁令、audit 抄 `fig-horizontal-swimlane`。

不确定图种 → `diagram-style-catalog`。图种门判定仍是 flowchart、只是太高 → 走本 skill，不是泳道。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 单主体时间线 / 阶段链，竖排超过一屏，要并排用右侧 | 跨层谁持球、同列下发上报 → `fig-horizontal-swimlane` |
| 两段故事（运行 / 关机）左右对照，仍是同一条时间 | 顶栏角色、列内作业框 → `fig-vertical-swimlane` |
| 用户要「两张竖卡并排 + 从左底接到右顶」 | 5 步以内小 flowchart → Mermaid + `useMaxWidth:false` |

## 几何（硬规则）

```
┌ 标题 ─────────────────────────────────────────────┐
│ ┌ 左卡（先发生）──┐     ┌ 右卡（后发生）──┐     │
│ │  步骤            │     │  步骤            │     │
│ │  ↓               │     │  ↓               │     │
│ │  最后一步 ───────┼──┐  │  第一步          │     │
│ └─────────────────┘  │  └─────────────────┘     │
│                      └──→ 接到右卡顶框左边         │
└──────────────────────────────────────────────────┘
```

- **一张 SVG**，左右卡画在同一 `viewBox`。禁止拆成两张 mermaid / 两个 SVG 再在中间夹装饰线。
- **左卡 = 时间上更早**，右卡 = 更晚。先左后右读。
- **卡内**：节点圆角矩形 `rx="6"`，主题一行、时间/注释放 `（）` 第二行。竖箭头从上框底到下框顶。
- **跨卡**：只连「左卡最后一框右边中点 → 右卡第一框左边中点」。走线必须是 **正交折线** `H … V … H …`（可一个圆角，禁止大贝塞尔鼓包）。
- **栏间距** 至少约 80px，竖段画在夹缝正中。边标（如「进入 reboot」）贴竖段右侧，不要压线。
- 顶栏可见标题与 `<title>` 同文。禁止「流程图」「如图」。

## 箭头（硬规则）

预览里 `marker-end` 经常画成折钩。**栏内向下箭头禁止用 `<marker>`。**

每条栏内边画两件：

```svg
<path d="M185 165 V172" stroke="#C9D1D9" stroke-width="2" fill="none"/>
<polygon points="179,172 185,180 191,172" fill="#C9D1D9"/>
```

竖线几乎顶到上框底和下三角顶；三角底边贴着下框顶。跨卡箭头可以用 `marker`（水平入框），或同样改成线 + `polygon`。

## 色板

画布 `#0D1117`。左卡带底 `#0D2433` / 描边 `#2E86AB`；右卡带底 `#3D2A00` / 描边 `#F18F01`（两卡必须能分开）。
节点抄 `markdown-export` 深彩色轮换（蓝 / 玫 / 橙 / 绿 / 紫 / 红），字 `#FFFFFF`。
跨卡折线 `#10B981`。栏内箭 `#C9D1D9`。

## 媒介

1. 写入目标 `.md` 内联 `<svg>`。开标签同一行；`<svg>` 到 `</svg>` 之间禁止空行。
2. `viewBox` 固定，`max-width` 等于画布宽。`marker id` 按文档唯一。
3. 禁止两张 mermaid 塞进 `<table>` / flex 再画夹缝线。禁止改 PNG。
4. 交卷跑 `audit_mermaid.py`（`svg-blank` / `svg-open-split`）。

## 工作流

1. 把步骤按时间切成两段（左先右后），两卡节点数尽量接近。
2. 先定框的 x/y/w/h，再画栏内竖箭，最后画跨卡折线（从框边到框边，不要从夹缝里起笔）。
3. 沿线走一遍：折线不穿框、三角不糊成钩、字不压线。

## 禁止

| 借口 | 实际 |
|------|------|
| 两张 mermaid 并排更像截图 | 跨图没有坐标系，连线只能凑。必须一张 SVG |
| `E --> F` 放进一张 mermaid LR | dagre 会把右卡第一格和左卡底对齐，并排等高就没了 |
| 夹缝里绝对定位一条贝塞尔 | 对不齐框边，鼓包很丑 |
| 栏内用 `marker-end` 省事 | 预览变折钩；画 `path` + `polygon` |
| 这是泳道 | 没有「谁的道」；只是流程图折列 |
| SVG 里空行分组 | CommonMark 截断 HTML |

对照合格：`rigol-ds5-boot-failure-and-fwupd-analysis.md` §2 时间线（正交折线、栏内实心三角）。
