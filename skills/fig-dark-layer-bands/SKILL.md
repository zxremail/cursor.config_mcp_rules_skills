# 深色分层色带（内联 SVG）

图种名：**深色分层色带**。Skill：`fig-dark-layer-bands`。

左栏层名、中间通栏色带、带内饱和色卡片，可选右侧竖条横切。上→下是归属（应用在上、总线/中间件在下），不是时序。层间**不画** `↓`、不画折线。

不确定图种 → `diagram-style-catalog`。
交卷：目标 `.md` **内联 SVG**。禁止 Mermaid `flowchart`。禁止 PNG / sidecar。

对照实现：`n.naishu.xdma` 知识库 `ai.cursor/architecture/path-alpha-card-type-handoff.md` **§1.4**（不要整图贴进对话；只抄几何与色槽）。

**转飞书：** 白底画板不要原样贴 `#0D1117`。几何不动；带改浅、卡改白、字改深（对照浅色中台分层截图）。源 `.md` 保持深彩色，不要补浅色对照节。走 `markdown-to-feishu-doc`。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 要看见「哪一层有哪些模块」，层名贴在左侧色块 | 层名写在框内、层间一句 ↓ → `fig-dark-layer-cards` |
| 一层里 4～6 张卡，或一层再分 2 个分组框 | 左栏是常驻 Manager、顶栏是业务胶囊 → `fig-dark-platform-stack` |
| 右侧要横切（观察 / 日志 / 监控 / 约束）跨若干层 | 关系/调用边 SVG → `fig-dark-layer-relations`；仍要 Mermaid → `mermaid-flowchart-layout` |
| 存储/设备用圆柱，中间件一层通栏 | 关/改/加/留 → `layer-action-capsule-diagram` |

点名「深色分层色带」或对照中台分层截图且要暗色主题 → 本 skill。只说「深色分层卡片」→ 卡片墙。

## 三区

```
┌层名┐ ╔ 色带 ══════════════════════╗ ┌观察┐ ┌监控┐
│ L1 │ ║ [卡] [卡] [卡] [卡]         ║ │横切│ │横切│
├────┤ ╠ 色带（可两组）              ╣ │    │ │    │
│ L2 │ ║ ┌组┐ ┌组┐                  ║ └────┘ │    │
├────┤ ╠ 色带（圆柱可选）            ╣        │    │
│ Ln │ ║ ( ) ( ) ( )                ║        │    │
└────┘ ╚════════════════════════════╝        └────┘
```

- 左栏色块与同行色带 **同 fill / 同描边**。
- 右侧竖条可只跨上面若干层（观察），另一条贯穿全高（约束/监控）。竖排文字 `rotate(90 cx cy)`。
- 卡片：标题一行 + 说明一行。禁止 `<foreignObject>`。
- 圆柱：上椭圆 + 矩形 + 下椭圆；标签写在柱下，仍落在该层带内。

## 色板（硬规则）

画布 `#0D1117`。带是暗底，卡是饱和填色，标题白字 `#FFFFFF`，说明用更深同色相（禁止深底深字、禁止浅整图底）。相邻层必须换色相。

| 槽 | 典型层 | 带 `fill` / `border` | 卡 `fill` / 说明字 |
|----|--------|----------------------|---------------------|
| 橙 | 业务 | `#3D2A12` / `#F0883E` | `#F0883E` / `#1A150D` |
| 红 | 管理面 | `#3A1518` / `#F85149` | `#E63946` / `#3A1518` |
| 绿 | 逻辑/库 | `#0F2A22` / `#3FB950` | 组 `#1E6B4E`，卡 `#2D936C` / `#0F2A22` |
| 橙黄 | 内核/数据 | `#3D2A00` / `#F18F01` | `#F18F01` / `#1A150D` |
| 蓝 | 存储/节点 | `#0D2433` / `#58A6FF` | 圆柱 `#2E86AB` / `#79C0FF` |
| 紫 | 依赖/硬件 | `#1A1028` / `#A371F7` | `#6A4C93` / `#1A1028` |
| 青 | 中间件/总线 | `#0B3D5C` / `#58A6FF` | `#1B4965` / `#79C0FF` |

横切：观察 `#163A4D` / `#58A6FF` / `#79C0FF`；监控或约束 `#3D2914` / `#F0883E` / `#FFCC80`。标题 `#F0F6FC`，副标题 `#8B949E`。

图下色键：`span` 字色抄该层 `border` 或卡 `fill`。禁止正文写可见 `#RRGGBB`。

## 几何（默认 1280 宽）

`viewBox="0 0 1280 H"`。标题区约 62；层隙 8。增减层只改 `H`，禁止缩小字号硬塞。

| 区 | x, w（约） | 高 | 圆角 |
|----|------------|----|------|
| 左栏层名 | 16, 100 | 同行带高 | 10 |
| 中间色带 | 124, 1028 | 单行卡 70；两组 118；圆柱 100 | 10 |
| 右侧竖条 | 1160 / 1216, 48 | 跨指定层 | 10 |
| 单行卡 | 带内 pad 12，列隙 8～10 | 46 | 8 |

同层 4 列均分；6 列变窄。两组时各占带宽一半，组内 2×2。中文一行约 10 字（6 列）或 14 字（4 列）。

## SVG 交卷

1. `<svg xmlns … viewBox="0 0 1280 H" … style="…background:#0D1117…">` **同一行写完**。
2. 内部 **禁止空行**；`</svg>` 后可空行。
3. `<title>` 与可见题同文；题用「深色分层色带：…」，禁止「示意图」「架构图」。
4. 写完：`python3 ~/.cursor/skills/markdown-export/scripts/audit_mermaid.py <md>`。

## 禁止项

- 做成 `fig-dark-layer-cards`（层间 `↓`、无左栏层名块、无右侧竖条）
- 做成 `fig-dark-platform-stack`（顶胶囊、嵌套开卡栈、底栏对齐硬件）
- Mermaid `subgraph` 冒充色带
- 层间箭头、跨带折线
- 浅色带 + 白卡当真源写进 Markdown
- 转飞书时把深底原样贴上白底画板
