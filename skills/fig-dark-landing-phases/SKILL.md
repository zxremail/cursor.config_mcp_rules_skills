# 深色落地阶段图（内联 SVG）

图种名：**深色落地阶段图**。Skill：`fig-dark-landing-phases`。

上半是交付阶段，下半是终局架构。角标一 / 二 / 三标的是**该块哪一阶段交付**（能力增量），不是「哪一层第几期才出现」。

不确定图种 → `diagram-style-catalog`。
交卷：目标 `.md` **内联 SVG**。禁止 Mermaid `gantt` / `flowchart`。禁止 PNG / sidecar。

对照实现：`n.naishu.xdma` 知识库 `ai.cursor/architecture/path-alpha-card-type-handoff.md` **§1.5**（不要整图贴进对话；只抄几何与阶段规则）。

**转飞书：** 白底画板不要原样贴 `#0D1117`。几何与角标不动；带改浅、卡改浅、字改深。源 `.md` 保持深彩色。走 `markdown-to-feishu-doc`。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 同一套架构按版本/期次长出来，要看见终局和顺序 | 只要「谁在哪一层」、无阶段 → `fig-dark-platform-stack` 或 `fig-dark-layer-cards` |
| 顶栏 3 个阶段胶囊 + 轴点，下面嵌套栈 + 右侧横切 | 左栏阶段 × 顶栏季度排期 → `task-roadmap-timeline` |
| 模块要标一期已有 / 二期才亮 / 三期加固 | 上下交错里程碑卡片 → `fig-alternating-timeline` |

点名「深色落地阶段图」或对照星环三阶段+座舱栈且要暗色主题 → 本 skill。

## 硬规则：能力增量，禁止按层切

1. 下面栈画**终局全图**（一期未亮的块也画，用角标区分）。
2. **底座**（内核、硬件、已存在的内核约束如 irq 单开）必须标 **一**。禁止把内核/卡画成第三阶段才出现。
3. **二** 只标本期才点亮的能力（例如开卡进程、认领协议），不是新长一层。
4. **三** 只标加固（停引擎接管、权限、看门狗）。可嵌在一期模块内侧小条，文案写清「不是新内核 / 不新增一层」。
5. 阶段名写能力（可查树 / 交开卡权 / 接管），不要写层名当阶段名。
6. 不要发明日历日期；没有排期就写「先交付 / 再交付 / 后加固」。

## 结构

```
[一 阶段胶囊] ——●—— [二 阶段胶囊] ——●—— [三 阶段胶囊]
     能力名 / 一句范围
┌左栏常驻┐  ┌ 嵌套终局栈 ─────────┐  ┌观察┐ ┌约束┐
│  角标   │  │ 跨列条 / 两列子系统  │  │角标│ │角标│
│         │  │ 共享库              │  └────┘ └────┘
│         │  │ 通栏内核（一）+ 三期小条 │
├ 硬件（一）┤  [卡 A] [卡 B]          │
└─────────┘  └────────────────────┘
底栏图例：一已有 / 二才亮 / 三加固
```

- 阶段胶囊中心与轴上圆点对齐。不画跨层折线。
- 角标：卡右上 22×16，字「一」「二」「三」，色抄该期胶囊。小组件父框已有角标则子卡不再贴。
- 卡片：标题一行 + 说明一行。禁止 `<foreignObject>`。

## 色板

画布 `#0D1117`。字浅底深。禁止浅整图底。

| 期 | 胶囊/角标 `fill` / `border` / 说明字 | 用在 |
|----|--------------------------------------|------|
| 一 | `#1E6B4E` / `#3FB950` / `#7EE787` | 已交付底座 |
| 二 | `#0D2137` / `#58A6FF` / `#79C0FF` | 本期才点亮 |
| 三 | `#3D2A00` / `#F18F01` / `#FFCC80` | 加固小条 |

终局栈色可抄 `fig-dark-platform-stack`（红管理面、蓝进程、紫库、橙内核条、绿硬件），但**角标色只跟期次走**，不要用层色冒充期次。轴 `#484F58`。标题 `#F0F6FC`。图下色键抄角标 `border`。禁止正文可见 `#RRGGBB`。

## 禁止项

- 按左栏 / 中间进程 / 内核来切三期（把底座标成最后一期）
- 做成无角标的 `fig-dark-platform-stack`
- 做成 `task-roadmap-timeline` 的浅色 Grid 甘特
- 层间 `↓`、跨区折线、Mermaid `gantt`
- 全图模块同样亮、看不出一期亮哪些
- 转飞书时把深底原样贴上白底画板
