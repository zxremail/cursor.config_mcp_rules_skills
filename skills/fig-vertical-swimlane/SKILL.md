# 深彩色垂直泳道图

顶栏写角色/模块，纵向色带分道，步骤落在对应列，时间从上到下。同行左右箭头是跨层交接。
**软件栈默认：应用列在左、硬件列在右。** 下发（调用）同行向右，上报（中断/完成）同行向左。

色板、节点括号、SVG 空行/开标签、PNG 禁令、audit、飞书浅色映射与 `fig-horizontal-swimlane` **同一套**。本页只写轴向差。不确定图种 → `diagram-style-catalog`。从「画流程图」进来 → `mermaid-flowchart-layout` 的 `choose-diagram.md`；命中本 skill 就不要写 `flowchart` / `sequenceDiagram`。

交卷：目标 `.md` **内联 SVG**（开标签同一行、内部无空行）。禁止 Mermaid `flowchart` / `gantt` / `sequenceDiagram` 硬凑。禁止改 PNG。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 一条因果链穿过 2 个以上模块，步骤框落在列里，时间往下读 | 左栏 + 时间左→右 → `fig-horizontal-swimlane` |
| 读者先看「谁的列」，再往下跟作业 | 贴顶生命线 + 消息 → `html-sequence-swimlane` / `sequenceDiagram` |
| 对照 BPMN 垂直：顶栏名、竖线、同行左右交接 | 职责墙 / 决策网 → `mermaid-flowchart-layout` |
| 调用栈下发/上报是主故事、层少步多、下落=下发更直观 | 仍走水平泳道，不要为「垂直」二字硬转 |

## 层序（硬规则）：应用在左、硬件在右

与水平图同一调用方向，只是转了 90°：读者从左列出发，往右走进机器。

| 左 → 右（默认） | 对应水平图 |
|-----------------|------------|
| 应用 / 业务 | 最上道 |
| API / 用户态库 | 第二道 |
| OS 适配 / 内核 | 第三道 |
| 板卡 / FPGA / 外设 | 最下道 |

因此：

- **下发**：箭头**向右**，指向硬件；实线。
- **上报**：箭头**向左**，回到应用；虚线。
- 图前读法第一行写明「应用在左、硬件在右。时间从上到下」。
- 未指定时禁止硬件在最左列。

色相按层抄水平 skill 色板（应用蓝 / API 绿 / 内核紫 / 硬件橙）。顶栏色块 = 水平图的左栏色。

## 几何（截图式样）

```
┌ 实际含义标题 ──────────────────────────────────────┐
├────────┬────────┬────────┬────────┤
│ 应用   │  API   │  内核  │  硬件  │
├────────┼────────┼────────┼────────┤
│ (起)步骤│        │        │        │
│        │ [步骤] │        │        │
│        │        │ [步骤] │ (止)   │
└────────┴────────┴────────┴────────┘
```

- **标题**：图顶 40px 可见短句，与 `<title>` 同文。禁止「流程图」「如图」「垂直泳道图」。
- **顶栏**：每道一个层/角色短名（单行）。顶栏上沿 6px 饱和色条。禁止文件名进顶栏；文件名只在列内节点。
- **竖带**：等宽。外框 + 竖线 + 顶栏横线。
- **时间**：上 → 下。同一时刻的跨层交接画在**同一行**；下发水平向右，上报水平向左。
- **同道内推进**：竖直向下箭头。
- **节点**：圆角矩形 `rx="6"`。主题一行，下一行 `（注释）`。不要椭圆。
- **边标签**：横箭头写在杆上方约 10px；竖箭头写在杆右侧约 8px。
- **箭头**：横轨 ≥ 2 时颜色分轨（抄水平 skill 轨色：左/中/右/第4）。线型：实线下发、虚线上报。单轨：下发 `#3370FF`、上报 `#00A870`、同层 `#06B6D4`。

行数跟步骤走，不要补空行。无决策菱形就不要硬加。

## 排线（硬规则）

把 `fig-horizontal-swimlane` 的竖轨规则**旋转 90°**：先定每条边的**横轨 y**，再画 `path`。

| 水平图 | 本图 |
|--------|------|
| 竖轨 x、一链一轨 | 横轨 y、一链一轨 |
| 同列只叠一链 | 同行只叠一链 |
| 列间留空 ~40px | 行间留空 ~40px |
| 源放中列（一源三出） | 源放中行，出边左 / 正下 / 右 |
| 往返：顶/底入 + 侧入 | 往返：左/右入 + 顶或底入，横段 y 不同 |
| 轨名在最长竖段 | 轨名在最长横段：`上轨 ·` / `中轨 ·` / `下轨 ·` |
| 禁止源那一道贴顶对穿 | 禁止源那一列里两条竖线贴边对穿 |

最少折：默认一个拐角。接到框边。禁止穿过框身、禁止贴框边滑行凑侧入。

交卷前五条（任一否 = 未完成）：

1. 没有线穿过框身。
2. 没有两条同色边在约 50px 内平行穿过 2 道以上。
3. 源节点那一列里没有两条竖线贴边对穿。
4. 横轨 ≥ 2 时，最长横段上有 `上轨 ·` / `中轨 ·` / `下轨 ·`，各轨 `stroke` 不同。
5. 没有贴框滑行，没有为凑侧入多出来的折。

## 图前读法

紧挨 `<svg>` 之上，同一 `<p>` + `<br>`（细则抄水平 skill）：

1. 顶栏是谁。应用在左、硬件在右。时间从上到下。同行向右是下发，向左是上报（及同道向下推进）。
2. 图上轨名带颜色：…（横轨 ≥ 2 才写）
3. 顶栏色条：…（整句亮色 span，写归属，不写文件）
4. 实线是下发，虚线是上报；线色跟轨走。

## 媒介 / 工作流

媒介 8 条全部抄 `fig-horizontal-swimlane`（内联 SVG、禁止空行、`translate(0,40)`、marker 按文档唯一、飞书浅色化不改 MD 暗色）。

1. 列出顶栏层/角色（左→右：应用在左、硬件在右）。
2. 列出步骤：谁、主题、括号注释、落在第几行。一源三出或往返：源放中行。
3. 先定横轨 y，再画 path。同行交接只给一条因果链；同道竖直画推进。
4. 上色、括号、五条自检。
5. 写入目标 md。

## 禁止

| 借口 | 实际 |
|------|------|
| 垂直泳道 = `sequenceDiagram` | 生命线是消息，不是列内步骤框。本图必须 SVG |
| flowchart 每列一个 subgraph | 带框竖链不是泳道 |
| 先画成水平再口头说垂直 | 轴向反了；要垂直就按本页顶栏+时间向下 |
| 应用在右 / 硬件在左（未指定） | 与水平图「硬件贴顶」同类，未完成 |
| 贴顶时序也叫垂直泳道 | 有生命线、无列内作业框 → `html-sequence-swimlane` |
| 下发画成向下 | 本图向下是**同列时间推进**；下发是向右 |

其余浅色、椭圆、文件名进栏、PNG、SVG 空行：同水平 skill「禁止」表。
