# 深色分层关系图（内联 SVG）

图种名：**深色分层关系图**。Skill：`fig-dark-layer-relations`。

深色整图底 + 分层套盒 + 左右列 + 语义箭头。上→下是层归属；**边**才是谁问谁、谁调用谁。一张图只回答一个问题（职责 / 时序 / 实现细节不要混装）。

不确定图种 → `diagram-style-catalog`。
交卷：目标 `.md` **内联 SVG**。禁止 Mermaid `flowchart` 围栏。禁止 PNG / sidecar / `<foreignObject>`。

对照实现：`n.naishu.xdma` 知识库 `ai.cursor/architecture/path-alpha-card-type-handoff.md` **§1.1**（只抄几何与色槽，不要把整图 SVG 贴进对话）。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 要看见层间**调用 / 查树 / 登记**，不是只看谁在哪一层 | 层间一句 ↓、无折线 → `fig-dark-layer-cards` |
| 同层并列两列，跨层**同列下落** | 左栏角色、时间从左到右 → `fig-horizontal-swimlane` |
| 用户点名 SVG / 不要 Mermaid 的分层架构 | 仍要 Mermaid 围栏 → `mermaid-flowchart-layout` |
| 嵌套层框、列框、饱和色节点 | 左栏层名色带 → `fig-dark-layer-bands`；顶胶囊平台栈 → `fig-dark-platform-stack` |

点名「深色分层关系图」或「用 SVG 画分层协作 / 关系图」→ 本 skill。口头「流程图」先过 `mermaid-flowchart-layout` 的图种门，不要直接当本图。

## 结构

```
╔ 层（外深） ══════════════════════╗
║ 层名                              ║
║ ╔ 左列 ══╗     ╔ 右列 ══╗        ║
║ ║ 节点    ║     ║ 节点    ║        ║
║ ║ 节点    ║     ║          ║        ║
║ ╚════════╝     ╚════════╝        ║
╚══════════════════════════════════╝
        ↓ 同列竖线 / 夹缝斜线
╔ 下一层（可无列，节点居中） ══════╗
```

- 主方向 TB。同层两列才套内框；单节点层不要空列框。
- 节点两行：主题 13 bold；注解 11，必须换行且括号，如 `（套接字或状态文件）`。
- 边画在框和节点之后，标签在线旁，不要压进节点。
- 跨列常驻主通路：总图可留**一条**夹缝斜线，并在导语指向后面的小图；禁止把斜线画成绕开整层的折线。小图可仍用短链 Mermaid（`useMaxWidth:false`）或同样 SVG。

## 色板（硬规则）

画布 `#0D1117`。套盒**外深内浅**，同色相不得同 fill。节点饱和填 + 白字 `#FFFFFF`。相邻层换色相。

| 槽 | 外框 fill / stroke | 列框 fill / stroke | 节点 fill / stroke |
|----|--------------------|--------------------|---------------------|
| 蓝 | `#0D2433` / `#2E86AB` | `#1B4965` / `#5BA3C9` | `#2E86AB` / `#1B4965` |
| 红 | `#3A1518` / `#E63946` | `#5A2A30` / `#FB7185` | `#E63946` / `#B52D38` |
| 紫 | `#1A1028` / `#6A4C93` | （无列则省略） | `#6A4C93` / `#4A3566` |
| 橙 | `#3D2A00` / `#F18F01` | | `#F18F01` / `#C67500` |
| 绿 | `#0F2A22` / `#2D936C` | | `#2D936C` / `#1E6B4E` |

标题 `#F0F6FC`，副标题 / 层间空档字 `#8B949E`。层名用该层浅字（蓝 `#79C0FF`、红 `#FFA198`、紫 `#D2A8FF`、橙 `#FFCC80`、绿 `#7EE787`）。

边（路径语义，不是时序蓝/绿）：

| 语义 | stroke | 宽 | dash |
|------|--------|----|------|
| 协调 / 查树 / 占用 | `#06B6D4` | 2 | 实线 |
| 配置 / 短探慢路径 | `#3B82F6` | 2 | `4 4` |
| 上层 API / `fpga_*` / 设备节点 | `#F59E0B` | 2.5 | 实线 |
| 硬件 / MSI / PCIe | `#67E8F9` | 2 | `12 4` |

图下色键 `span` 字色抄节点 fill 或边 stroke。禁止正文可见 `#RRGGBB`。

## 几何（默认 1100 宽）

`viewBox="0 0 1100 H"`。内容 x=28、宽 1044。标题区约 56。增减节点只改 `H`，禁止缩小字号硬塞。

| 件 | 约 |
|----|----|
| 层框 | x=28 w=1044，rx=8，描边 2 |
| 左列 | x=42 w=470 |
| 右列 | x=590 w=466（夹缝约 78，专走行） |
| 节点 | w=280 h=56 rx=6；左 cx=277，右 cx=823，通栏居中 cx=550 x=410 |
| 层内边距 | 页眉约 22；列头约 18；列内节点竖隙 ≥36 |
| 层间 | ≥48，给箭头和边标 |

`<defs>` 里每种边色一个 `marker`（id 加图前缀，如 `dlr-arr-cyan`），`refX="7"` `orient="auto"`。路径停在节点边，不要穿框。同列竖线对齐该列 cx；跨列走夹缝 x≈551，再折入目标顶边。禁止贴框滑行凑侧入。

字号：标题 20 · 层名 15 · 列名 12 · 节点 13/11 · 边标 11。字体 `sans-serif`。

## SVG 交卷

1. `<svg xmlns … viewBox="0 0 1100 H" … style="…background:#0D1117…">` **同一行写完**。
2. 内部 **禁止空行**；分组用 `<!-- app -->`。`</svg>` 后可空行。
3. 可见标题与 `<title>` 同文；题写图意，禁止「示意图」「架构图」「流程图」。
4. 画序：底 → 层框 → 列框 → 节点 → 边 → 全部文字。
5. 写完：`python3 ~/.cursor/skills/markdown-export/scripts/audit_mermaid.py <md>`。

## 禁止项

- Mermaid `flowchart` / `subgraph` 冒充本图
- 做成 `fig-dark-layer-cards`（只↓、无边）
- 做成水平/垂直泳道（角色道 + 时间轴）
- 外框与内框同一 fill
- 主题和注解糊成一行、注解无括号
- 一图混职责和时序
- 为预览空白改 PNG
