# 深彩色水平泳道图

左栏写角色/模块，横向色带分道，步骤落在对应行，时间从左到右。同列上下箭头是跨层交接。

整个底色使用深彩色配色方案，以便适合在暗色主题环境中查看，同时保持良好的对比度和可读性。

不确定是不是这种图 → 先读 `diagram-style-catalog`。
交卷：写入目标 `.md` 的**内联 SVG**。禁止用 Mermaid `flowchart` / `gantt` / `sequenceDiagram` 硬凑。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 一条因果链穿过 2 个以上模块/进程/层次 | 贴顶角色 + 生命线向下 → `html-sequence-swimlane` |
| 读者要先看「谁的道」，再看时间 | 人员排期/人力胶囊 → `task-assignment-timeline` |
| 对照 BPMN：左栏名、横线、同列下落 | 职责墙/跨层关系网 → `mermaid-flowchart-layout` |
| 完成中断、作业、回调谁消费 | 浅色分层卡片墙 → `fig-tinted-layer-cards` |

## 几何（截图式样）

```
┌ 实际含义标题 ─────────────────────────────────────────┐
├────────┬─────────────────────────────────────────────┤
│ 角色 A │  (起) 步骤                                    │
│ 角色 B │        [步骤] ──→ [步骤]                      │
│ 角色 C │                         [步骤]                │
│ 角色 D │                              (止) 步骤        │
└────────┴─────────────────────────────────────────────┘
```

- **标题**：图顶 40px 栏里必须有**可见**短句（`<text>`），与 `<title>` 同文。取最近小节 + 图意，无句号。禁止「流程图」「如图」「示意图」「水平泳道图」。只写无障碍 `<title>`、图上看不见 = 未完成。
- **左栏**：每道一个短名（单行）。左侧再加 6px 饱和色条。
- **横带**：等高（默认每道 100px）。外框 + 横线 + 左栏竖线。
- **时间**：左 → 右。同一时刻的跨层交接画在**同一列**，箭头竖直穿过带。
- **同道内推进**：水平箭头。
- **节点**：一律圆角矩形（`rx="6"`）。不要椭圆，不要把起止画成圆。主题一行，注释一行。
- **注释放在括号内**：第二行必须是 `（补充描述）`，用中文括号。不要无括号的副标题，不要把注释写进主题同一行。
- **边标签**：紧贴箭杆。竖箭头写在杆右侧约 8px，水平箭头写在线上方约 10px，垂直对齐该段中点。不要把字对齐到节点右缘（会和箭杆空出一截）。机制如 `MSI / MSI-X`；约束如 `不是函数指针`。

列数跟步骤走，不要为「好看」补空列。无决策菱形就不要硬加。

## 色板（硬规则）

画布 `#0D1117`。带底外深、左栏同色相略亮。节点饱和填色 + 白字 `#FFFFFF`。禁止白底、浅灰默认框、深底深字。

默认四道（可少可多；相邻道必须能分开）：

| 道 | 带底 | 左栏 | 色条 / 节点 fill | 节点 stroke | 用途例 |
|----|------|------|------------------|-------------|--------|
| 1 | `#3D2A00` | `#5A3D00` | `#F18F01` | `#C67500` | 硬件 |
| 2 | `#1E1530` | `#2A1F40` | `#6A4C93` | `#4A3566` | 内核 |
| 3 | `#0D241C` | `#16382C` | `#2D936C` | `#1E6B4E` | 管理进程 |
| 4 | `#0D2433` | `#163A4D` | `#2E86AB` | `#1B4965` | 业务 |

固定件：

| 件 | 色 |
|----|----|
| 格线 / 外框 | `#30363D` |
| 箭头 / 普通边标 | `#E8EAED` |
| 约束边标 | `#F18F01` |
| 左栏角色名 | `#FFFFFF` |
| 标题栏底 | `#161B22` |
| 标题字 | `#FFFFFF` |

图下若用「橙 / 紫 / 绿 / 蓝」指节点，色名字色必须等于该图节点 `fill`（`markdown-export` §10）。

第五道以后在同色相里再开一档更深/更亮，不要回到浅灰。

## 媒介

1. 用户点了 `.md` → **原地**把该图换成内联 `<svg>`（`viewBox` 固定，`max-width` 100%）。
2. 有 `ai.cursor/` 时路径走 `ai-cursor-doc-output`。
3. 不要另存 PNG；不要为了「像 Mermaid」再留一份 subgraph。
4. `<title>` 与顶栏可见标题同文；短句、无「流程图/如图」。
5. `marker id` 按文档唯一，避免同页多图箭头错绑。
6. 泳道本体放在 `translate(0,40)` 里，`viewBox` 高度 = 泳道高 + 40。

## 工作流

1. 列出左栏角色（上→下，与层次一致）。
2. 列出步骤：谁、主题、括号注释、落在第几列。
3. 同列下落画跨层；同道水平画推进。
4. 按上表上色；注释全部加 `（）`。
5. 写入目标 md；图下补色名图例（若用了色名）。

## 禁止

| 借口 | 实际 |
|------|------|
| Mermaid subgraph 也是泳道 | 那是带框竖链；左栏格子必须 SVG |
| 先浅色 BPMN，暗色以后再改 | 第一次就深彩色；浅底白框 = 未完成 |
| 只给节点描边、带底仍是白/浅灰 | 带底、左栏、节点 fill 都要深彩色 |
| 副标题不写括号更干净 | 注释放在括号内 |
| 贴顶时序也叫泳道 | 角色在顶、时间向下 → `html-sequence-swimlane` |
| 颜色区分模块就够，不必左栏 | 用户要水平泳道就是因为只靠颜色不够直观 |
| `<title>` 已经有了 | 那是无障碍属性；读者要看见顶栏标题 |
| 起点终点用椭圆更像 BPMN | 一律圆角矩形；不要圆、不要椭圆 |

## 骨架

节点第二行必须带 `（）`。色值抄上表，不要另选浅色。

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 920 440" role="img"
     style="max-width:920px;width:100%;background:#0D1117;border-radius:8px;">
  <title>短句图意</title>
  <rect x="0" y="0" width="920" height="40" fill="#161B22"/>
  <text x="460" y="26" text-anchor="middle" font-size="16" font-weight="600"
        fill="#FFFFFF" font-family="sans-serif">短句图意</text>
  <g transform="translate(0,40)">
    <!-- 每道：带底 rect + 左栏 rect + 6px 色条 + 角色名 -->
    <!-- 步骤：一律圆角 rect，fill=该道饱和色，字 #FFFFFF -->
    <!-- 主题一行；下一行 （注释） -->
    <!-- 箭头 stroke=#E8EAED + marker -->
  </g>
</svg>
```
