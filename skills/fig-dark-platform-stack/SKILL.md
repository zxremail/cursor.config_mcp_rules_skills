# 深色平台栈（内联 SVG）

图种名：**深色平台栈**。Skill：`fig-dark-platform-stack`。

左栏常驻管理面、顶栏多业务胶囊、中间嵌套栈、底栏成对硬件、右侧横切。不是上→下「一层一张卡」的卡片墙，也不是流程图。

不确定图种 → `diagram-style-catalog`。
交卷：目标 `.md` **内联 SVG**。禁止 Mermaid `flowchart`。禁止 PNG / sidecar。

对照实现：`n.naishu.xdma` 知识库 `ai.cursor/architecture/path-alpha-card-type-handoff.md` **§1.4**（不要整图贴进对话；只抄几何与色槽）。

## 何时用 / 不用

| 用 | 不用 |
|---|---|
| 产品/机箱：常驻 Manager 或域在左侧，多种业务在顶栏 | 只要「谁在哪一层」、层间一句 ↓ → `fig-dark-layer-cards` |
| 中间要嵌套「两列子系统 + 跨列共享条」 | 关系/调用边 → `mermaid-flowchart-layout` |
| 底栏两类硬件与顶栏业务左右对齐 | 浅米色座舱截图且用户要浅色 → 几何可抄，色板不要用本表 |
| 右侧观察面 / 约束 / 工具链横切 | 关/改/加/留 → `layer-action-capsule-diagram` |

点名「深色平台栈」或对照座舱截图且要暗色主题 → 本 skill。只说「深色分层卡片」→ 卡片墙。

## 五区（从左到右、从上到下）

```
┌左栏常驻┐  业务软件  [胶囊 A] [胶囊 B]
│ 芯片→  │  ┌ 中间嵌套栈 ─────────────┐  ┌观察┐ ┌约束┐
│ 管理面 │  │ 跨列条（占用/总线）      │  │横切│ │横切│
│        │  │ [子系统 A] [子系统 B]    │  │    │ │    │
│        │  │    跨列共享（库/引擎）    │  └────┘ └────┘
│        │  │ 通栏（内核）              │
│        │  └─────────────────────────┘
│        │  硬件  [卡 A] [卡 B]
└────────┘
```

- 左栏与中间栈之间允许 **一条** 箭头：左栏芯片 → 栈顶跨列条。不要再画网状边。
- 顶栏胶囊与底栏硬件 **左右对齐**（A 上对 A 卡，B 上对 B 卡）。
- 卡片文案：标题一行 + 说明一行。禁止 `<foreignObject>`。

## 色板（硬规则）

画布 `#0D1117`。字浅底深：标题 `#FFFFFF` / `#F0F6FC`，说明用该槽 `text`。禁止浅整图底、禁止深底深字。

| 槽 | 用在哪 | 区框 `fill` / `border` | 内卡片 `fill` | 字 `text` |
|----|--------|------------------------|---------------|-----------|
| 红 | 左栏管理面；右侧硬约束 | `#161B22` 或 `#3A1518` / `#F85149` | `#2D1215`；强调用 `#E63946` | `#FFA198` |
| 蓝 | 顶栏胶囊、子系统、观察面 | `#0D2137` 或 `#0D2433` / `#58A6FF` | `#2E86AB` | `#79C0FF` |
| 紫 | 占用/总线条、共享库 | `#1A1028` / `#A371F7` | `#6A4C93` | `#D2A8FF` |
| 橙 | 通栏内核；左→栈箭头 | `#1A150D` / `#F0883E` | 同左 | `#FFCC80` |
| 绿 | 底栏硬件 | `#122117` / `#3FB950` | 同左 | `#7EE787` |

箭头 `stroke`/`fill`：`#F59E0B`。中间嵌套栈外框用紫槽，内子系统用蓝槽，外深内浅、fill 不得相同。

图下色键：`span` 字色抄本图 `border` 或卡片 `fill`（灰说明用 `#8B949E`）。禁止正文写可见 `#RRGGBB`。

## 几何（默认 1320×640）

`viewBox="0 0 1320 640"`。内容不要压到边；左栏与栈之间留出箭头。

| 区 | x, y, w, h（约） | 圆角 |
|----|------------------|------|
| 左栏 | 16, 16, 152, 608 | 16 |
| 顶栏胶囊 | 248 / 564, 20, 300, 44 | 22 |
| 中间栈外框 | 248, 80, 616, 420 | 16 |
| 底栏硬件 | 248 / 564, 516, 300, 108 | 14 |
| 右侧栏 | 888 / 1104, 80, 200, 544 | 16 |

侧标（业务软件 / 开卡栈 / 硬件）在 x≈188，`#8B949E`，12–13px。增减卡片只改对应区高度并重算 `viewBox`，禁止缩小字号硬塞。中文一行约 14 字。

## SVG 交卷

1. `<svg xmlns … viewBox="0 0 1320 640" … style="…background:#0D1117…">` **同一行写完**。
2. 内部 **禁止空行**；`</svg>` 后可空行。
3. `<title>` 与可见题同文；题用「深色平台栈：…」，禁止「示意图」「架构图」。
4. 写完：`python3 ~/.cursor/skills/markdown-export/scripts/audit_mermaid.py <md>`。

## 禁止项

- 做成 `fig-dark-layer-cards` 那种通栏层框 + 层间 `↓`
- 用 Mermaid `subgraph` 冒充五区
- 左栏、顶胶囊、右侧栏、底栏硬件对不齐或 A/B 交叉
- 多条跨区折线（只保留左芯片→栈顶条这一条）
- 浅米色整图当真源（那是对照截图，不是本色板）
