# Mermaid 流程图排版与架构图连线

不确定图种 → `diagram-style-catalog`。

**格式不准降级。** 完整做法、合格/反例、图例方案 D 以 [references/layout.md](references/layout.md) 为准（原 §0–§12 全文）。多 subgraph、跨域架构、独立图例时 **必须 Read layout.md**，不要只凭本页省略隐形 `linkStyle`、同列下落、节点 `<b>/<small>`。

配色条文见 **`markdown-export`** §5（完整 [export.md](../markdown-export/references/export.md)）。交付前：

```bash
python3 ~/.cursor/skills/markdown-export/scripts/audit_mermaid.py ./path.md
```

## 0. 深彩色 + 标题（先于排版）

写入 `.md` 的围栏必须：

```
---
title: 业务进程到特权守护进程的调用关系
---
%%{init: {'theme': 'dark'}}%%
flowchart TB
```

禁止「流程图」「如图」。节点深彩色 `fill` + 浅字。禁止只写 `theme: dark`。连线色不能代替节点色。

### 0.1 嵌套 subgraph

外框与内框 `fill` 不得相同（外深内浅）。例：外 `#0D2433`，内 `#1B4965`，节点 `#2E86AB`。单层不强制两套色，仍须深彩色。

## 1. 多 subgraph 分行

`flowchart TB`；块内 `direction LR`。无语义边才用 `A --- B`（subgraph **ID**）+ 立刻：

```
linkStyle N opacity:0,stroke-width:0px
```

**禁止裸 `~~~`。** 层间已有 `-->` / `==>` 不要再加占位边。先写齐占位 `---` 再写语义边，隐形序号才是 `0..(k-1)`。预览能数出无箭头灰线 = 不合格。

## 2. 长链

超过 4–5 个横向节点：拆链或改 `TB`。

## 3. 跨域架构（格式）

**一张图只回答一个问题**（职责 / 时序 / 实现细节不同装）。混装症状：单点 ≥4 条语义边、下层往上指、3 种以上线型、边在写脉宽而章节是协作。不必等用户坚持再拆。

默认 `flowchart TB` 分层；同层并列用左右列，跨层 **同列下落**。子组件收进运行时容器，避免双汇聚。边写在图底部。总图裁掉的跨列**常驻主通路**必须另画小图（一条通路一张，`useMaxWidth:false`，不加图例）。完整画法 Read layout.md §3。

## 4. linkStyle 语义色

| 语义 | 箭头 | 色 |
|------|------|-----|
| 上层 API | `==>` | `#F59E0B` 2.5px |
| 主数据 | `-->` | `#10B981` |
| 协调/信令 | `-->` | `#06B6D4` |
| 配置慢路径 | `-.->` | `#3B82F6` dash 4 4 |
| 物理信号 | `-.->` | `#67E8F9` dash 12 4 |
| 外部延伸 | `-->` 实线 | `#94A3B8` 2.5px |

占位边计入序号。先隐形占位，语义色从 k 起算。

### 4.1 时序方向（不要用上表）

向右请求实线 `#3370FF`；向左返回虚线 `#00A870`；暗底自调用 `#E8EAED`。`sequenceDiagram`：请求 `->>`、返回 `-->>`（不能单条 `linkStyle`；HTML 导出由 md2html 补蓝/绿）。边上说明文字不改成蓝/绿。

## 5. 箭头说明

跨层、易误解的边写 `|传递内容或机制|`，不要只写「连接」。过长用 `<br/>`。边上已有说明则不要再复制图例。

## 6. 图例

默认不加。仅当：跨域多层 **且** ≥3 种语义线型 **且** 无法写满边标签。此时独立第二块、方案 D（圆点对 + 隐形 `---` 留白 + `useMaxWidth:false`），见 layout.md §6.3。禁止裸 `~~~`。

## 10. 小图

决策/三五步：`useMaxWidth:false`，禁止独立图例。

## 11. 文字露出

框裁字、内层压标题、箭头穿字 = 没画完。用 `<br>` 撑开框，不要缩小字号硬塞。

## 12. 主题 + 注解（格式，不准改配方）

名+注必须：

```
ID["<b>模块主题</b><br/><small>（补充描述）</small>"]
```

禁止糊一行、只换行无括号、只括号不换行、中文斜体、整格 `font-style:italic`、把模块属性写到箭头上。仅有名字时不要编空括号。转飞书须保留加粗+缩小括号，见 `mermaid-to-feishu-whiteboard`。

## 交付清单

YAML 标题、theme dark、节点 fill、嵌套分色、无 `~~~`、占位已隐形、一图一问、小图 `useMaxWidth:false`、主题注解 HTML、`audit_mermaid.py ok`。文字露出靠预览，脚本扫不了。
